## Overview

This repository contains our official submission for the **PsyDefDetect Shared Task** at **BioNLP 2026**. We fine‑tune domain‑specific transformer models (MentalBERT, MentalRoBERTa, MentalXLNet) to classify 9 defense mechanisms in the ESConv dialogue dataset.
